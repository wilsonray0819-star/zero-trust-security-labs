# Zero Trust Security Labs (Microsoft Cloud)

This repository documents a hands-on implementation of Zero Trust security principles using Microsoft cloud technologies.  
The project is structured as a series of progressive labs, each aligned to a core Zero Trust pillar, culminating in a unified architecture capstone.

---

## 🧠 Zero Trust Overview

Zero Trust is a security model based on the principle of **never trust, always verify**.  
Access decisions are made dynamically using identity, device posture, application context, data sensitivity, and continuous risk evaluation.

This project follows Microsoft Zero Trust guidance:

- Verify explicitly
- Use least privilege access
- Assume breach

---

## 🧩 Lab Structure

| Lab | Focus Area | Description |
|----|-----------|-------------|
| **Lab 01** | Identity & Conditional Access | MFA, authentication strength, and identity-based access enforcement |
| **Lab 02** | Device Security & Compliance | Intune device compliance and endpoint protection |
| **Lab 03** | Network Segmentation | Network controls and Zero Trust Network Access concepts |
| **Lab 04** | Application Access | Conditional Access and modern authentication for applications |
| **Lab 05** | Data Protection & DLP | Sensitivity labels, DLP policies, and data governance |
| **Lab 06** | Zero Trust Architecture | Capstone architecture integrating all security pillars |

Each lab includes configuration details, validation steps, and screenshots for auditability.
